# 🍴 Zomato Restaurant Analysis – Excel

## 📌 Project Overview

An Excel-based data analysis project using Zomato restaurant data to identify trends and insights related to restaurant locations, cuisines, ratings, and customer preferences.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Dashboard Creation

## 📊 Key Analysis

* Restaurant distribution by country and city
* Analysis of restaurant ratings
* Popular cuisines
* Restaurant price range analysis
* Online delivery availability
* Table booking analysis
* Location-based restaurant trends

## 📈 Dashboard

The project includes an interactive Excel dashboard with KPI cards, charts, and slicers for exploring restaurant data.

## 🔍 Key Skills Demonstrated

* Data cleaning and preparation
* Exploratory data analysis
* Pivot table analysis
* Dashboard development
* Data visualization
* Business insight generation
